📖 使用说明：如何拿到小时级账单（双层打包）

  1. 每天导出一个 ZIP：DeepSeek 开放平台 → 用量（Usage）→ 导出数据， 日期范围选择同一天（例如 8月6日 ~ 8月6日），下载得到当天的小时级 ZIP（如 usage_data_2026-08-06_2026-08-06.zip）。 单日导出的账单是逐小时记录的，才能区分高峰/空闲时段。
  2. 重复操作：想统计几天就导出几天，每天一个 ZIP。
  3. 双层打包：把每天的 ZIP 放进同一个文件夹 → 全选 → 压缩成一个 ZIP。 即外层 ZIP 里面装的是一堆「天级 ZIP」——本工具会递归解压，自动识别出小时级数据。
  4. 拖进来：把外层 ZIP（或任意单日 ZIP）拖入上方区域，即可按高峰/空闲时段精确计算涨价后的费用。
✅ 推荐：单日导出（小时级）→ 按真实高峰/空闲时段精确计价，并给出高峰用量占比。
⚠️ 注意：若直接导出多天范围（如 8月1日 ~ 8月17日），账单只有天级聚合数据（每天一条，无小时信息）， 无法区分高峰/空闲，工具会退回「全空闲 / 全高峰」上下界估算模式。

高峰时段定义（北京时间）：9:00–12:00、14:00–18:00，其余为空闲时段；空闲价为高峰价的一半。 新价格（元/百万 Token）见页面内计算逻辑，Flash 与 Pro 各分空闲/高峰两档。
